== Overview

This directory houses the foundational game design pillars, combat mechanics, spatial topography,
and testing philosophy for *Tenebris and Lux* in the **Kingdom of Sacyra**.

== Game Design Manifest

1. **[tactical_trpg_system.adoc](file:///home/professorseanex/Tenebris%20and%20Lux/docs/game_design/tactical_trpg_system.adoc)**  
   *Tactical Strategy RPG (TRPG) System Specification*: Comprehensive blueprint of the dual-layer combat system:
   - Phase 1: Grid-based tactical battlefield (tile movement, terrain, directional facing, Zone of Control).
   - Phase 2: Cinematic combat resolution (traditional side-scroll / action-based battle clashes).
   - Dual-protagonist synergy (Elijah Ro-enheart's frontline defense & Katrina Jaren's outrider skirmishing).
   - Tandem linked combat arts and moral sway integration.

2. **[relics_and_combat.adoc](file:///home/professorseanex/Tenebris%20and%20Lux/docs/game_design/relics_and_combat.adoc)**  
   *The Twin Relics, Combat Stances & Moral Sway*: Detailed specifications of the Shield of Lux, Sword of Tenebris, the 4-stance state machine, and the `[-100, +100]` moral continuum.

3. **[world_topography.adoc](file:///home/professorseanex/Tenebris%20and%20Lux/docs/game_design/world_topography.adoc)**  
   *World Topography & Tactical Encounter Design*: The geography of the Kingdom of Sacyra, defensive provinces, battlefield terrain modifiers, and threat scaling.

4. **[game_testing.adoc](file:///home/professorseanex/Tenebris%20and%20Lux/docs/game_design/game_testing.adoc)**  
   *Game Dev Testing vs Software Testing*: Deep dive into continuous state invariants, golden master replay parity, softlock immunity stress tests, and 60 FPS frame-budget latency headroom.
