== Overview

This directory preserves the developer logs recorded during **November 2026** for *Tenebris and Lux*.

`architecture/` for foundational engine design, verification strata, and interactive debugging; and
`lore_and_design/` for macro-historical canon, thematic triads, and the morality architecture.
