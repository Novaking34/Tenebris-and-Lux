== Overview

This directory preserves the canonical biographical dossiers, martial doctrines,
psychological profiles, and socio-political affiliations for all figures within
the **Kingdom of Sacyra** across *Tenebris and Lux*. Grounded in the original
2014–2018 RPG Maker foundations and refined for the custom C11 Tactical Strategy
RPG (TRPG) engine, this archive details heroes, court officials, provincial
citizens, ancient sages, and void adversaries.
