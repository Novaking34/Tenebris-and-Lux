/**
 * @enum log_severity
 * @brief Graded severity taxonomy for engine diagnostics and telemetry events.

 * ### For Game Designers & Non-Programmers:

    LOG_SEV_TRACE,        /**< High-frequency per-tick calculation telemetry. */
