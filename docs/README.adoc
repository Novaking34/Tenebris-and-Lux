AsciiDoc (`.adoc`) documentation standard for clean, modular, and comprehensive game development manuals.

== 2. Ontological Documentation Principles

All documentation adheres to three core rules:

* **Form Precedes Fullness**: Define rules, boundaries, and mathematical invariants before authoring prose or gameplay tables.
* **Bi-Directional Traceability**: Every mechanic introduced in documentation maps directly to an invariant verification function in the engine.
* **Universal Accessibility**: Ground the mechanics so they function identically whether driven by terminal keyboards or graphical viewports.
