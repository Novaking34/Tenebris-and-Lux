[cols="2,3,3", options="header"]
|===
| Category | Tracked Elements / Types | Starting Baseline (Playtest Default)

| **The 6 Main Elements**
| **Earth**, **Wind**, **Fire**, **Water**, **Light (Lux)**, **Darkness (Tenebris)**
| All units start at `100%` (Neutral); Elijah holds innate `75%` Lux resist; Katrina holds `75%` Tenebris resist.

| **Combined / Secondary Elements**
