// --- Sub-Assembly 3.1: Snapshot Ring, Locking & GCD Wrap Rotation ---
== Snapshot Capture, Locking & Time-Travel Rewind

Calling `debug_record_snapshot()` freezes a copy of `debug_state_fields_t` alongside a 32-bit FNV-1a checksum and the synchronized `log_sequence_id` from `cog.log`. Calling `debug_lock_snapshot()` protects milestone frames from overwrite; when the ring wraps, `debug.c` uses O(cap) GCD wrap rotation to evict unlocked slots while preserving chronological order. `debug_rewind_to_snapshot()` and `debug_diff_snapshots()` restore or compare any retained frame:

include::../../snapshots/snap_debug_rewind_group.adoc[]

// --- Sub-Assembly 3.2: Stepping Mode, Watchpoints & AWAIT Gate ---
== Stepping Modes, Breakpoints & `DEBUG_STEP_AWAIT`

[cols="2,4",options="header"]
|===
| Capability | Public Contract in `debug.h`

| Execution Pacing & Await
| `debug_set_step_mode()`, `debug_is_awaiting()`, `debug_can_step()`, and `debug_resolve_await()` pause execution deterministically after a fault or watchpoint hit until resolved.

| Simulation Watchpoints
| `debug_add_breakpoint()`, `debug_remove_breakpoint()`, `debug_clear_breakpoints()`, and `debug_check_breakpoints()` watch up to `16` numeric thresholds (`hp == 0`, stance shift, alignment breach, etc.) in O(n).

| Provenance Queries
| `debug_is_data_driven()` and `debug_is_safe_mode()` distinguish disk JSON profiles from compiled `.rodata` ROM fallback mode cleanly.
