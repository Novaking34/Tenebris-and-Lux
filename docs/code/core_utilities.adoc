== Overview

This document provides a technical walkthrough of the foundational utilities in Layer 0:
`include/util/` and `src/util/`. These modules provide mathematical clamping, string parsing,
2D geometry bounding, and high-resolution monotonic timing. They have zero heap allocations,
zero external dependencies, and complete reentrancy.

== 1. Mathematical Invariant Utilities (`math_utils.h` & `math_utils.c`)

Provides axiomatic numerical bounds enforcement:

[source,c]
----
int math_clamp_int(int val, int min_val, int max_val);
int math_saturating_sub(int val, int sub_val);
int math_saturating_add(int val, int add_val, int max_val);
int math_nudge_toward(int val, int target, int step);
int math_scale_ratio(int val, int max_val, int target_scale);
----

=== Architectural Roles:
* `math_clamp_int`: Guarantees values stay within strict limits (e.g. `moral_sway` within `[-100, +100]`).
* `math_saturating_sub`: Guarantees non-negative reduction down to $0$ without integer underflow (e.g. `sword_edge`, `threat_hp`).
* `math_saturating_add`: Guarantees addition saturates at a ceiling (`MAX_RESONANCE`) without integer overflow.
* `math_nudge_toward`: Steers values toward an equilibrium anchor (e.g. moving moral sway toward $0$ during equilibrium stance).
* `math_scale_ratio`: Safe integer ratio scaling for HUD meter fill calculations.

== 2. String Manipulation Utilities (`string_utils.h` & `string_utils.c`)

Provides safe, bounded, in-place string manipulation:

[source,c]
----
void str_safe_copy(char *dst, const char *src, size_t dst_size);
void str_trim_inplace(char *str);
bool str_case_eq(const char *s1, const char *s2);
bool str_contains_nocase(const char *haystack, const char *needle);
----

=== Architectural Roles:
* `str_safe_copy`: Guarantees null-termination and prevents buffer overflows.
* `str_trim_inplace`: Strips leading and trailing whitespace in-place via safe `memmove`.
* `str_case_eq`: Case-insensitive string comparison for CLI command verbs.
* `str_contains_nocase`: Substring search for flexible player commands and stance selection.

== 3. 2D Geometry Utilities (`geom_utils.h` & `geom_utils.c`)

Provides screen-space coordinates and bounding-box hit testing:

[source,c]
----
typedef struct {
    int x;
    int y;
    int w;
    int h;
} geom_rect_t;

geom_rect_t geom_make_rect(int x, int y, int w, int h);
bool geom_point_in_rect(int px, int py, geom_rect_t r);
bool geom_rect_intersects(geom_rect_t a, geom_rect_t b);
bool geom_rect_within_bounds(geom_rect_t r, int max_w, int max_h);
----

=== Architectural Roles:
* `geom_point_in_rect`: Point-in-rectangle hit testing for mouse clicks on GUI buttons.
* `geom_rect_intersects`: Axis-Aligned Bounding Box (AABB) collision testing between UI components to prove no overlap.
* `geom_rect_within_bounds`: Layout boundary audit asserting all buttons reside within window dimensions.

== 4. Monotonic Timing Utilities (`time_utils.h` & `time_utils.c`)

Provides high-resolution timing and non-drifting frame pacing:

[source,c]
----
double time_get_monotonic_ms(void);
double time_get_monotonic_us(void);
void time_sleep_ms(double ms);
----

=== Architectural Roles:
* `time_get_monotonic_us`: Microsecond precision clock for simulation latency benchmarking (< 50 $\mu\text{s}$ per turn).
* `time_sleep_ms`: Sleep wrapper using `nanosleep` for maintaining 60 FPS frame rates without CPU spinlocks.

== 5. Central Manifest & Pre-Flight System (`manifest.h` & `manifest.c`)

Transforms declarative Block 1 file headers into executable compiled metadata structures (`module_metadata_t`) enforcing contract revisions, DAG dependency tracking, memory models, and pre-flight machine audits:

[source,c]
----
typedef enum {
    ALLOC_ZERO_HEAP = 0,    // Pure stack/static execution (Layer 0 guarantee)
    ALLOC_FIXED_POOL,       // Fixed static ring/pool buffers
    ALLOC_ARENA,            // Frame/scene arena allocator
    ALLOC_DYNAMIC           // Managed heap allocation
} alloc_policy_t;

typedef enum {
    CONCURRENCY_REENTRANT = 0, // Thread-safe, stateless pure functions
    CONCURRENCY_THREAD_LOCAL,  // Per-thread state
    CONCURRENCY_MAIN_THREAD    // Viewport/GUI event loop affinity
} concurrency_policy_t;

typedef struct {
    /* 1. Identity & Provenance */
    const char *module_id;          // e.g. "core.util.time"
    const char *file_name;          // e.g. "time_utils.h"
    module_layer_t layer;           // Stratum in architectural hierarchy
    struct {
        uint8_t major;
        uint8_t minor;
        uint8_t patch;
    } version;
    uint8_t interface_rev;          // Contract ABI revision
    const char *last_updated;       // ISO 8601 full date: "YYYY-MM-DD"
    const char *description;        // Plain-English mission statement
    
    /* 2. Architectural Dependencies */
    size_t dependency_count;
    const char *dependencies[MANIFEST_MAX_DEPENDENCIES]; // Upstream module IDs required
    
    /* 3. Resource & Execution Contracts */
    alloc_policy_t alloc_policy;
    concurrency_policy_t concurrency;
    uint32_t max_budget_us;         // Max execution latency budget (in microseconds)
    
    /* 4. Invariant Contracts */
    size_t invariant_count;
    const char *invariants[MANIFEST_MAX_INVARIANTS];
    
    /* 5. Pre-Flight Machine Self-Audit */
    diag_result_t (*preflight_check)(void);
} module_metadata_t;

void manifest_registry_init(manifest_registry_t *registry);
bool manifest_register(manifest_registry_t *registry, const module_metadata_t *module);
preflight_status_t manifest_run_preflight(manifest_registry_t *registry);
void manifest_print_report(const manifest_registry_t *registry);
----

=== Architectural Roles:
* `module_metadata_t`: Immutable static metadata node binding provenance, version, interface contract revision (`interface_rev`), ISO 8601 update date (`2026-10-26`), upstream DAG dependencies, allocation policy, concurrency guarantees, and self-auditing function pointer per file.
* `manifest_registry_t`: Fixed-capacity registry (capacity 32) operating with zero dynamic allocations (`ALLOC_ZERO_HEAP`).
* DAG Dependency Enforcement: Validates that all upstream modules declared in `dependencies[]` are registered prior to runtime; missing prerequisites halt execution with `SEVERITY_FATAL`.
* Graded Policy Evaluator: Enforces the 5-tier diagnostic severity hierarchy (`PASS` < `INFO` < `WARNING` < `CRITICAL` < `FATAL`) and 4-tier engine launch status (`READY`, `WARNINGS`, `DOWNGRADED`, `HALTED`).
* Loose-Bolts Enforcement: Prevents the game engine from booting if any core mathematical, timing, memory, or state invariant fails prior to runtime.
