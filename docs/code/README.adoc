== Overview

This directory provides deep-dive walkthroughs and technical specifications of the
source code implementation across the five layered strata of **The Big Machine**
(`engine/`) and **The Master Turn Gear** (`game/`).

== Implementation Manifest

1. **xref:core_utilities.adoc[core_utilities.adoc]** +
   *Layer 0 Core Utilities*: `engine/src/core/` and `engine/include/core/`. Details bounded math, saturation arithmetic, 2D AABB geometry, monotonic time, 60 Hz fixed-timestep clock pacing, bounded string safety, formula evaluation, and universal orchestrators (audio bus, screen transitions).

2. **xref:io_pipeline.adoc[io_pipeline.adoc]** +
   *Layer 0 Zero-Heap I/O Pipeline*: `engine/src/io/` and `engine/include/io/`. Details the bounded POSIX VFS (`fs_utils`), upward repository path resolution (`path_finder`), streaming memory-bounded JSON parsing (`json_utils`), and pre-flight master manifest loading (`master_loader`).

3. **xref:logging_system.adoc[logging_system.adoc]** +
   *Layer 0 Categorized Flight Logging*: `engine/src/log/` and `engine/include/log/`. Details severity taxonomy (`LOG_LEVEL_TRACE`..`FATAL`), engine vs. game channel bitmasks, the 256-entry zero-heap circular ring buffer, automatic rolling log rotation, and data-driven telemetry profiles.

4. **xref:debug_system.adoc[debug_system.adoc]** +
   *Layer 0 State Debugger & Diagnostics*: `engine/src/debug/` and `engine/include/debug/`. Details frozen state snapshot ring buffers, deterministic FNV-1a 32-bit state hashing, forensic stream exporters (NDJSON, CSV, Diagnostic Report), live ASCII inspection cards, active tripwire matrix, and time-travel state rewind.

5. **xref:simulation_engine.adoc[simulation_engine.adoc]** +
   *Layer 1 Simulation Engine*: `game/src/` and `game/include/` (`combat/`, `hero/`, `relics/`, `world/`, `ending/`, `dispatch/`). Details pure headless TRPG simulation, twin relic stance state machines, moral sway continuum `[-100, +100]`, and action dispatching.

6. **xref:presentation_gui.adoc[presentation_gui.adoc]** +
   *Layer 2 Presentation Viewports*: `engine/src/viewport/` and `engine/include/viewport/` (`raster/`, `hud/`, `reel/`, `styling/`). Details the Movie Reel architecture: horizontal Push/Pull scene transitions across 5 canonical screens, vertical Pop-Out/Sink-In depth kinematics, high fantasy palettes, and 2.5D dimetric grid projection.

7. **xref:audio_subsystem.adoc[audio_subsystem.adoc]** +
   *Layer 0/2 Audio Event Bus & Mixer*: `engine/src/audio/` and `engine/include/audio/`. Details the 7-channel mixing bus (Master, BGM, Ambience, Combat SFX, Tactical SFX, UI, Stingers), zero-heap 128-event ring buffer, attenuation matrices, and quarantined emergency fallback profile.

8. **xref:test_suite.adoc[test_suite.adoc]** +
   *Layer 4 Verification & Ontological Test Suite*: `tests/` (`functional/`, `unit/`, `integrated/`, `system/`). Details 54 CMake/CTest targets, invariant assertions, golden master replays, softlock stress tests, and automated sub-millisecond benchmarking.
