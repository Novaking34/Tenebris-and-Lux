## 2. Relational Connectives & Modal Polarity of `!`

### 2.1 Five Relational Connectives

* **`!` (`BUT`):** Adversative caveat ratchet — $A \text{ ! } B$ runs $A$, **but** unwinds if caveat $B$ returns `-1` or `NULL`.
* **`::` (`AND` Independent):** Sequential pipeline gearing requiring coupled execution (e.g., never update standard without audit).
* **`:` (`IN RELATION TO`):** Proportional attribution ($A : B :: C : D$) binding essence to context `[Definition] : {Context}`.
* **`|` (`OR`):** Disjunctive branch valve (`--> AWAIT | --> PROCEED`).
* **`&` (`BOUND PAIR`):** Inseparable dual-pin lock uniting coupled axioms (`Truth & Life & Justice`).

### 2.2 Prefix Guard (`[!X]`) vs. Postfix Escalation (`[X!]`)

```text
         PREFIX GUARD [!...]                        POSTFIX ESCALATION [...!]
+-----------------------------------+      +-----------------------------------+
|              [!DING]              |      |              [DING!]              |
|        "Hold on, BUT notice"      | ---> |    "Condition occurred, BUT       |
|       Level 1 Advisory Guard      |      |    you failed to heed; ESCALATE"  |
|     Pauses execution smoothly     |      |       Level 2 Hard Tripwire       |
|    Prevents drift before damage   |      |   Demands full seam breakdown     |
+-----------------------------------+      +-----------------------------------+
```
